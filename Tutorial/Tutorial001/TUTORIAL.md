**Learn C# with Visual Studio Code on Ubuntu Linux**

## 1. Development Environment Setup

### 1.1 Verify or install .NET 10

Open a Linux terminal (or **Terminal → New Terminal** in VS Code):

```bash
env -u DOTNET_ROOT /usr/bin/dotnet --info
```

Your existing Phase 8 environment uses .NET SDK **10.0.114**. If .NET 10 is not installed on another Ubuntu machine and its configured APT repositories provide the package:

```bash
sudo apt update
sudo apt install dotnet-sdk-10.0
```

Verify:

```bash
env -u DOTNET_ROOT /usr/bin/dotnet --version
```

**Why `env -u DOTNET_ROOT`?** On your Linux system, it avoids interference from an older Snap-based .NET installation and uses the native `/usr/bin/dotnet` SDK.

### 1.2 Verify Visual Studio Code

```bash
code --version
```

Install the Microsoft C# extension:

```bash
code --install-extension ms-dotnettools.csharp
```

Optional: install **C# Dev Kit** for additional project tooling:

```bash
code --install-extension ms-dotnettools.csdevkit
```

### 1.3 Install supporting tools

```bash

```

### 1.4 Complete environment check

## 3. Understand the Project File

Open `Tutorial001.csproj`:

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
  </PropertyGroup>
</Project>
```

| Setting | Meaning |
|---|---|
| `Microsoft.NET.Sdk` | .NET build tools |
| `OutputType` | Executable application |
| `TargetFramework` | .NET 10 |
| `ImplicitUsings` | Automatically imports common namespaces |
| `Nullable` | Enables nullable reference type analysis |

A `.csproj` file plays a role similar to a build configuration in C/C++ projects.

## 4. Your First RPG Program

Open `Program.cs` in VS Code and replace its contents with:

```csharp
using System;

Console.WriteLine("================================");
Console.WriteLine("        SOSCSRPG Tutorial       ");
Console.WriteLine("================================");
Console.WriteLine();

string playerName = "Adventurer";
int hitPoints = 20;
int maximumHitPoints = 20;
int gold = 10;
int experiencePoints = 0;
int level = 1;

Console.WriteLine($"Name:  {playerName}");
Console.WriteLine($"Level: {level}");
Console.WriteLine($"HP:    {hitPoints}/{maximumHitPoints}");
Console.WriteLine($"Gold:  {gold}");
Console.WriteLine($"XP:    {experiencePoints}");

Console.WriteLine();
Console.WriteLine("Welcome to the world of SOSCSRPG!");
```

Save with **Ctrl+S**, then run in the integrated terminal:

```bash
env -u DOTNET_ROOT /usr/bin/dotnet run
```

Expected output:

```text
================================
        SOSCSRPG Tutorial
================================

Name:  Adventurer
Level: 1
HP:    20/20
Gold:  10
XP:    0

Welcome to the world of SOSCSRPG!
```

### What did we learn?

- `using System;` imports a namespace.
- `Console.WriteLine()` prints a line to the terminal.
- `string` holds text; `int` holds 32-bit signed integers.
- `$"HP: {hitPoints}"` is **string interpolation**.
- Modern C# supports **top-level statements**, so this small program does not need an explicitly written `Main()` method.

## 5. C# Variables and Data Types

```csharp
int hitPoints = 20;
string playerName = "Adventurer";
bool isAlive = true;
double criticalChance = 0.15;
decimal itemPrice = 12.50m;
```

| Type | Purpose | Example |
|---|---|---|
| `int` | Signed integer | `20` |
| `string` | Text | `"Adventurer"` |
| `bool` | True/false | `true` |
| `double` | Floating-point number | `0.15` |
| `decimal` | Decimal arithmetic | `12.50m` |

C# also supports type inference:

```csharp
var gold = 10;           // inferred as int
var name = "Adventurer"; // inferred as string
```

Unlike a dynamically typed variable, `var` still has a fixed type determined at compile time.

## 6. Your First RPG Combat

Append this code to the end of `Program.cs`:

```csharp
Console.WriteLine();
Console.WriteLine("A venomous spider appears!");

string monsterName = "Venomous Spider";
int monsterHitPoints = 10;
int weaponDamage = 4;

Console.WriteLine($"Enemy: {monsterName}");
Console.WriteLine($"Enemy HP: {monsterHitPoints}");

Console.WriteLine();
Console.WriteLine("You attack with your rusty sword!");

monsterHitPoints -= weaponDamage;

Console.WriteLine($"Damage dealt: {weaponDamage}");
Console.WriteLine($"Enemy HP: {monsterHitPoints}");

if (monsterHitPoints <= 0)
{
    Console.WriteLine($"You defeated {monsterName}!");
    gold += 5;
    experiencePoints += 10;
}
else
{
    Console.WriteLine($"{monsterName} is still alive!");
}

Console.WriteLine($"Current Gold: {gold}");
Console.WriteLine($"Current XP: {experiencePoints}");
```

Run again:

```bash
env -u DOTNET_ROOT /usr/bin/dotnet run
```

The spider begins with 10 HP and takes 4 damage. It survives with **6 HP**, so the player receives no reward yet.

### Operators

| Operator | Meaning |
|---|---|
| `=` | Assignment |
| `+=` | Add and assign |
| `-=` | Subtract and assign |
| `==` | Equal to |
| `!=` | Not equal to |
| `<=` | Less than or equal to |
| `&&` | Logical AND |
| `||` | Logical OR |

## 7. Debugging with VS Code

1. Open **Run and Debug** with **Ctrl+Shift+D**.
2. Open `Program.cs`.
3. Click in the gutter beside `monsterHitPoints -= weaponDamage;` to add a breakpoint.
4. Press **F5** and choose the C#/.NET debugger if prompted.
5. Inspect `monsterHitPoints` and `weaponDamage` in the **Variables** panel.
6. Press **F10** to step over the subtraction and inspect the updated HP.

| Shortcut | Action |
|---|---|
| `F5` | Start / Continue |
| `F9` | Toggle breakpoint |
| `F10` | Step Over |
| `F11` | Step Into |
| `Shift+F5` | Stop debugging |
